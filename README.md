# BMI Calculator 💪

A simple BMI Calculator built using Spring Boot and Tailwind CSS.

## 🚀 Features
- Calculate BMI instantly
- Clean UI using Tailwind
- Backend powered by Spring Boot

## 🛠 Tech Stack
- Java (Spring Boot)
- HTML, CSS (Tailwind)
- Maven

## ▶️ How to Run
1. Clone repo
2. Run:
   mvn spring-boot:run
3. Open: http://localhost:8080
